# 🌸 Celestial Birthday - Zero-Gravity Floating Interface

A sleek, romantic, and interactive single-page birthday web application featuring a zero-gravity floating interface set against a dreamy animated white & blush pink celestial background with procedural cosmic ambient music and sound effects.

---

## ✨ Features

- **🌸 Dreamy White & Pink Celestial Canvas**: Multi-layered animated background featuring soft pastel clouds, twinkling rose-gold and crystal stars with 3D touch/mouse parallax, and shooting stars.
- **📸 6 Floating Polaroid Memories**:
  - Classic square Polaroid frames with frosted glow, washi tape accents, and handwritten captions.
  - Interactive Lightbox with high-resolution view, next/previous navigation, and in-app photo replacement.
- **💌 14 Pre-Loaded Pastel Sticky Notes**:
  - Categorized under **Support**, **Love**, **Wish**, and **Promise**.
  - Angled floating cards with pushpins and click-to-read ambient modal.
- **🪐 True Zero-Gravity Physics**:
  - Non-linear floating drift with randomized durations and phase offsets.
  - Free drag-and-drop interaction across the entire screen.
  - "Reset Orbit" button that animates all items back to their initial constellation positions.
- **📱 Dual Viewing Modes**:
  - **Zero-Gravity Orbit Mode**: Elements dynamically scale so that cards stay within the viewport on mobile devices.
  - **Mobile Story Feed Mode**: A vertical magazine-style story layout tailored for easy scrolling on phones.
- **🎵 Romantic Happy Birthday Song & SFX**:
  - Full iconic melody of *"Happy Birthday To You"* in a gentle music-box / celesta timbre.
  - Harmonized with lush warm chords (F, C7, Bb, F/C, F) in 3/4 time that loops continuously.
  - Support for uploading and playing custom recorded birthday MP3 tracks.
  - Interactive starlight chime sound effects on card clicks, drags, and releases.
  - "Wish 🌸" celebration stardust and heart confetti explosion.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS + Custom Glassmorphism
- **Animations & Physics**: Framer Motion
- **Icons**: Lucide React
- **Confetti**: Canvas Confetti
- **Audio**: Web Audio API (Synthesizer & Sound Effects)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/ahsifat-66/birthday.git
cd birthday
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 4. Build for Production
```bash
npm run build
npm run preview
```
